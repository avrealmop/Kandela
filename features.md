# Features

## Per-monitor control

Each monitor keeps its own profile — brightness, color temperature, contrast, and hardware brightness. Adjust one display without touching the others. Switch between "All monitors" and a specific display from the dropdown.

## Brightness & contrast

Software dimming via gamma ramps and a topmost overlay veil. Works on any display, including virtual monitors (spacedesk, DisplayLink) where the gamma path is dead.

## Color temperature (Premium)

Shift the screen from warm (night) to cool. Values are per-monitor and survive reboot.

## Hardware brightness — DDC/CI

Real backlight control on monitors that support DDC/CI, like a built-in brightness key. Falls back to software dimming when unsupported.

## Window transparency (Premium)

Make the Kandela window itself see-through with a slider (30–100%). Handy to keep an eye on content behind the panel.

## Scheduling (Premium)

Turn the effect on/off automatically at set times, including overnight wrap (e.g. 22:00 → 06:30).

## Keyboard shortcuts (Premium)

- **Toggle** — turn the effect on/off
- **Brightness up/down** — step by 5%

Register any key combo; conflicts are detected before saving.

## Automatic update checks

Kandela notifies you once per new version. Microsoft Store builds update through the Store; EXE builds check GitHub releases. Nothing installs without your approval.

## System tray

Kandela lives in the tray. Click the icon to show/hide, right-click for quick actions (open, toggle, quit). The tray icon matches your active theme. Enable **Close to tray** and **Run at startup** in Settings to keep it always at hand.
