# Installation

## Get Kandela

Kandela is a Windows app (x64) distributed through the **Microsoft Store**.

1. Open the **Microsoft Store** on your PC
2. Search for **Kandela**
3. Click **Get** / **Install**
4. Launch Kandela from the Start Menu — it appears in the system tray

> Requires Windows 10 version 1809 (build 17763) or later, 64-bit.

## First run

On first launch, Kandela asks to detect your monitors. If a display isn't showing, click the **Reload** button in the Monitor card.

To run Kandela automatically at startup, enable **Start with Windows** in Settings.

## Uninstall

Uninstall from **Settings → Apps → Kandela**, or from the Microsoft Store app page. Uninstalling restores your screens to normal immediately.
