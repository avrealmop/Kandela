# Installation

## Get Kandela

Kandela is a Windows app (x64). Two ways to install:

**Option A — Microsoft Store (recommended)**

1. Open the **Microsoft Store** on your PC
2. Search for **Kandela**
3. Click **Get** / **Install**
4. Launch Kandela from the Start Menu — it appears in the system tray

**Option B — Direct download (EXE)**

1. Open the [latest release](https://github.com/avrealmop/Kandela/releases/latest)
2. Download `Kandela-Setup-1.0.10.exe`
3. Run the installer and follow the steps
4. Launch Kandela from the Start Menu — it appears in the system tray

> Requires Windows 10 version 1809 (build 17763) or later, 64-bit.

## First run

Kandela detects your monitors automatically on launch. If a display isn't showing, click the **Reload** button in the Monitor card.

To run Kandela automatically at startup, enable **Run at startup** in Settings.

## Premium activation

Buy Premium to receive a license key by email, then open Settings → **Enter key**, paste the key, and press **Activate**. Manage or remove the license anytime from Settings → **Manage**.

## Uninstall

Uninstall from **Settings → Apps → Kandela** (Store and EXE versions alike). Uninstalling restores your screens to normal immediately.
